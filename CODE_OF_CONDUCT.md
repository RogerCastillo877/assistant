# Code of Conduct

## Our Commitment

The OSEF community is committed to fostering an open, respectful, inclusive, and collaborative environment for everyone.

We believe that engineering excellence is achieved through constructive discussion, diverse perspectives, continuous learning, and mutual respect.

Every participant is expected to contribute to a professional environment where ideas can be challenged without attacking individuals.

---

# Our Values

The OSEF community is guided by the following values:

- Respect
- Integrity
- Collaboration
- Curiosity
- Transparency
- Professionalism
- Accountability
- Continuous Improvement

These values apply to all interactions within the project.

---

# Expected Behavior

Contributors are expected to:

- Treat everyone with respect and professionalism.
- Welcome constructive feedback.
- Accept technical disagreements respectfully.
- Base discussions on evidence and engineering reasoning.
- Share knowledge openly.
- Help newcomers learn and contribute.
- Respect different backgrounds and experience levels.
- Assume good intentions while communicating clearly.

---

# Unacceptable Behavior

The following behaviors are not acceptable:

- Harassment or personal attacks.
- Discrimination of any kind.
- Intimidation or threats.
- Offensive or abusive language.
- Deliberate misinformation.
- Trolling or disruptive behavior.
- Publishing private information without permission.
- Bad-faith participation intended to disrupt the project.

Technical disagreement is encouraged.

Personal hostility is not.

---

# Engineering Discussions

OSEF encourages healthy technical debate.

Engineering decisions should be evaluated according to:

- technical merit;
- evidence;
- specifications;
- long-term maintainability;
- architectural consistency.

Arguments should focus on ideas rather than individuals.

---

# Artificial Intelligence

OSEF welcomes the responsible use of Artificial Intelligence.

Contributors may use AI-assisted tools when appropriate.

However, contributors remain responsible for:

- understanding their contributions;
- validating generated content;
- ensuring compliance with project specifications;
- maintaining engineering quality.

AI assists engineering.

It does not replace accountability.

---

# Community Responsibilities

All community members share responsibility for maintaining a healthy environment.

This includes:

- reporting unacceptable behavior;
- supporting respectful communication;
- encouraging collaboration;
- protecting the integrity of the project.

---

# Enforcement

Project maintainers may take appropriate action when this Code of Conduct is violated.

Possible actions include:

- private warning;
- request for corrective action;
- temporary suspension of participation;
- permanent removal from the community.

Responses should always be proportional, transparent, and respectful.

---

# Scope

This Code of Conduct applies to:

- project discussions;
- issues;
- pull requests;
- documentation;
- code reviews;
- community meetings;
- official communication channels.

---

# Reporting

If you experience or witness behavior that violates this Code of Conduct, please report it to the project maintainers.

Reports should include:

- a description of the incident;
- relevant context;
- supporting evidence when available.

All reports will be handled confidentially whenever practical.

---

# Our Philosophy

OSEF is founded on the belief that great engineering requires great collaboration.

Respect strengthens discussion.

Discussion strengthens ideas.

Ideas strengthen engineering.

Engineering strengthens intelligent systems.

---

# A Shared Commitment

By participating in OSEF, every contributor agrees to uphold this Code of Conduct and to help create an engineering community where people can collaborate, learn, innovate, and build trustworthy intelligent systems together.

## Engineering Over Ego

Engineering decisions should never be based on authority, popularity, or personal preference alone.

The best ideas should emerge through evidence, experimentation, and respectful technical discussion.

Changing one's mind in light of better evidence is considered a strength, not a weakness.
