# OSEF Runtime Examples

## Purpose

This directory contains fully valid OSEF examples.

Every example contained here MUST:

- validate against the official JSON Schemas;
- represent a complete engineering artifact;
- follow the OSEF Specification;
- be usable as documentation;
- be usable as automated validation tests;
- be usable as reference implementations.

Examples are intentionally small and focused.

They demonstrate the canonical structure of each artifact without introducing unnecessary complexity.
