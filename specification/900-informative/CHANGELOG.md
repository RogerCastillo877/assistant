# [0.1.0] - 2026-07-26

## Foundation Release

This release establishes the initial engineering foundation of OSEF.

### Added

#### Foundation Specifications

- Manifesto
- Vision
- Project Charter
- Core Principles

#### Engineering Specifications

- Architecture
- Software Development Life Cycle (SDLC)
- Governance
- Meta Model
- Artifact Model

#### Supporting Specifications

- Blueprint
- Roadmap
- Glossary

#### Configuration

- osef.yaml

### Engineering Highlights

- Established the engineering philosophy of OSEF.
- Defined the core engineering principles.
- Introduced the conceptual Meta Model.
- Defined the Artifact Model and engineering traceability.
- Established the reference architecture.
- Defined the official Software Development Life Cycle.
- Introduced the governance model.
- Standardized document metadata.
- Adopted Semantic Versioning.
- Established engineering traceability as a first-class concept.

# Versioning Policy

OSEF follows Semantic Versioning.

- **MAJOR** — Incompatible architectural or specification changes.
- **MINOR** — Backward-compatible additions.
- **PATCH** — Corrections, clarifications, and editorial improvements.
